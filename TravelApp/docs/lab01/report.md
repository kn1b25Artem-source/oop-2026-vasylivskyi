# Звіт до лабораторної роботи №1

## Тема
Створення та організація проєкту на C#/.NET у середовищі Visual Studio.

## Варіант
6 — Туристична агенція

## Мета
Ознайомитися з організацією проєкту на платформі .NET, створити початкову
модель предметної області (тури та клієнти туристичної агенції) та набути
навичок створення й використання об'єктів класів.

## Хід виконання
1. Створено консольний проєкт `TravelApp` (шаблон Console App, C#, .NET 10).
2. Створено простір імен `TravelApp.Models` та каталог `Models/`.
3. У каталозі `Models/` створено класи:
   - `Tour` з властивостями `Country`, `City`, `Price`;
   - `Client` з властивістю `Name`.
4. У файлі `Program.cs` створено по два об'єкти кожного класу
   (`tour1`, `tour2`, `client1`, `client2`) та виведено інформацію про
   них у консоль.
5. Проєкт успішно скомпільовано (`dotnet build`) та запущено (`dotnet run`).
